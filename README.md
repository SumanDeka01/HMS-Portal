# Hostel Gate Pass Management System

A web-based application for digitizing hostel gate-pass management, making pass applications, approvals, and verification easier and more organized.

## Overview

The Hostel Gate Pass Management System provides a centralized platform for students to apply for gate passes and track their status, while wardens can manage pass approvals and security personnel can verify approved passes.

## Features

- **Student Portal** — Apply for gate passes and track application status.
- **Gate Pass Approval** — Wardens can review, approve, or reject requests.
- **QR Code Generation** — Generate QR codes for approved gate passes.
- **Pass Verification** — Support gate-pass verification by security personnel.
- **Authentication & Authorization** — Role-based access for different users.
